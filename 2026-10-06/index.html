4. UNO Q CPU_ON hotplug fix

Fixed locally Agatti CPU_OFF leaves the core powered in WFI. The old CPU_ON path nevertheless repeats the cold power-up sequence, changing memory-power and retention controls on a core whose supply never collapsed. The fix detects an already-powered core, preserves those controls and pulses only core reset. First cold power-up is unchanged. The exact internal stall instruction, individual offending power bit and electrical reason for device susceptibility remain unobserved.

Crossover tests show baseline and SR both fail on Device A and both pass on Device B. A rebuilt unmodified image, a data-layout-only control and a read-only control still fail on Device A; the uninstrumented reset change passes. Tracing masks the failure and is not the fix. 471177, 471176, 471179, 471180, 471185, 471193, 471216, 471190

PAS TEE NULL resource table

Fixed in the Linux TEE backend Stopping a remote processor clears the cached table pointer but can leave a nonzero size. If restart has no input resource table, the TEE backend uses that stale size and copies from NULL. The fix normalizes NULL input to zero size before both the TEE size query and the copy. Real input tables remain unchanged; the generic remoteproc caller is unchanged.
